# Contributing

Thank you for your interest in contributing to Japanese Memory Game.

This project welcomes contributions that improve the learning experience while respecting privacy, licensing, accessibility, and the free-software direction of the app.

## Project Values

- Keep the app lightweight, understandable, and accessible.
- Prefer clear code over clever code.
- Respect learners from different backgrounds and levels of Japanese knowledge.
- Avoid surveillance-based monetization and manipulative product patterns.
- Preserve the ability to inspect, run, modify, and share the source code.
- Keep educational content accurate, attributed, and properly licensed.

## Licensing

By contributing source code, you agree that your contribution is licensed under GPL-3.0-or-later.

By contributing original educational content, you agree that your contribution is licensed under CC-BY-4.0 unless a different compatible license is explicitly documented.

Do not contribute copied third-party content unless its license is compatible and attribution is included.

## Brand Assets

Logos, mascots, visual identity assets, trade names, and brand materials are not licensed as free software or Creative Commons content unless explicitly stated.

Do not reuse or contribute brand assets unless you have the legal right to do so and the maintainer explicitly accepts them.

## Development

Install dependencies and run the app locally:

```sh
npm install
npm run dev
```

Before proposing a change, run the checks that are practical for your environment. At minimum, make sure the app still builds and the affected user flows still work in a browser.

```sh
npm run build
```

## Privacy And Security Expectations

Contributions should not introduce advertising trackers, behavioral analytics, unnecessary third-party scripts, or avoidable personal-data collection.

Security-sensitive logic should be handled server-side where appropriate. Public browser code should not be trusted to enforce paid access, account permissions, or private data protection.

If you discover a vulnerability, follow [SECURITY.md](SECURITY.md) instead of opening a public issue with sensitive details.

## AI-Assisted Contributions

AI-assisted contributions are acceptable when a human contributor remains responsible for the result.

Contributors should review AI-generated code carefully, test the affected behavior, and make sure the contribution matches the project's licensing, privacy, and quality expectations.
