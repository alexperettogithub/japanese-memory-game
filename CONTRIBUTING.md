# Contributing

Thank you for your interest in contributing to Japanese Memory Game.

## Licensing

By contributing source code, you agree that your contribution is licensed under GPL-3.0-or-later.

By contributing original educational content, you agree that your contribution is licensed under CC-BY-4.0 unless a different compatible license is explicitly documented.

Do not contribute content copied from third-party sources unless its license is compatible and attribution is included.

## Brand Assets

Do not contribute or reuse logos, mascots, visual identity assets, or brand materials unless you have the legal right to do so and the project maintainer explicitly accepts them.

Brand assets are all rights reserved unless explicitly stated otherwise.

## Development Values

- Keep the project lightweight.
- Prefer clear code over clever code.
- Respect learners from different backgrounds.
- Avoid surveillance-based monetization or manipulative product patterns.
- Preserve the ability to run and modify the project freely.

## Local Development

Run a local static server from the project root:

```sh
npx serve .
```
